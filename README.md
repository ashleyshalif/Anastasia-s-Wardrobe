# 👗 Anastasia’s Wardrobe

> *"Thoughtfully chosen styles for every age, every day, and every occasion. Beautifully chosen. For every chapter of her life."*

**Anastasia’s Wardrobe** is a luxury, editorial e-commerce web application inspired by boutique European ateliers. Designed specifically for multi-generational fashion across **Girls 2–12**, **Teens 13–17**, and **Women’s Atelier Collections**, it delivers an uncompromising digital boutique shopping experience.

---

### ✨ Key Features

* **Editorial Atelier Storefront**: Seasonal invitation heroes, curated department directories, tactile knitwear spotlights, and boutique letters.
* **Refined Catalog & Search**: Dynamic department taxonomy, multi-faceted filtering (colors, sizes, price), and real-time live piece search drawer.
* **Product Detail Views (PDP)**: Interactive size selection, garment care & fabric accordions, atelier styling notes, and interactive measurement guides.
* **Complete Commerce Journey**: Full shopping bag, promotional voucher engine (`ATELIER10`), handwritten gift note integration, and a streamlined 2-step checkout.
* **Customer Account & 30-Day Returns**: Order history, live parcel tracking milestones (Blue Dart Express), saved address book, and an interactive doorstep return & exchange wizard.
* **Support & Atelier Concierge**: Customer help center, measurement guides, courier logistics policies, and bespoke appointment booking.
* **Production-Ready Architecture**: Typed API service interfaces, fallback architecture, payment gateway hooks (Razorpay / Stripe / UPI), and zero-config `.env.example`.
